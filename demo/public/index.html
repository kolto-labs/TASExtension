    Set the path budget

    The thug plans a path in one tick and may expand only this many nodes. With a small budget it walks toward the best node it saw, so it can get stuck in the pocket. In the real game the budget is 10 ms of wall time. A busy machine searches less, and the path changes from run to run. Here it is a node count, so every run matches.
