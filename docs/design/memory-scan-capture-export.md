# Retain a captured memory scan locally

The shared Value scanner now offers Export captured scan. It serializes its current and previous successful byte captures and latest comparison from memory already held by the page. It never calls the backend reader, refreshes registers, resumes execution or scans another range.

Schema telos.memory-scan-capture/v1 retains each buffer's session, PID, workspace epoch, ISO capture time, exact address/length, value type, declared pointer width/byte order, evidence source and normalized target declaration. Raw bytes preserve float bit patterns. The latest rule/value/stride, previously considered candidate offsets and all matched offsets are included; the200-row display limit does not truncate exported matches. Initial scans identify explicit range/stride as their candidate basis. This is the latest comparison, not complete prior scan history. Declared target metadata does not prove loaded executable identity. A scan capture is not a whole-runtime snapshot or replay receipt.

Export is admitted only for the current session/PID/epoch/model/source, with no scan in flight. It uses a dated local JSON download and a2MiB serialized limit. A successful new capture, explicit Reset or existing context invalidation revokes the prepared URL; failed reads retain previous results. Export errors retain the captured bytes/results, and the UI says download requested rather than claiming a completed download. No browser upload, private asset publication or new backend capability.
