# Kolto Labs

Life support for the Odyssey engine.

Kolto Labs is a GitHub org, [github.com/kolto-labs](https://github.com/kolto-labs), for KotOR I and II tools. Three repos there are ready to use right now:

- **[kq](https://github.com/kolto-labs/kq)**, a command line for KotOR files. It reads an install in place and answers questions about it like plain text: which copy of a resource the game loads, what is in it, where a string appears.
- **[kotor-formats](https://github.com/kolto-labs/kotor-formats)**, the format library kq uses. One copy of the byte layouts for KotOR I and II files, so the tools built on it cannot drift apart.
- **[kpharness](../README.md)**, this repo. A harness and TAS toolkit; KotOR I first, KotOR II planned.

Nothing else in the org is ready for use yet. If a repo is not on this list, treat it as unfinished.

We don't ship game files. Every tool here expects you to bring your own copy.
