# Kolto Labs

Life support for the Odyssey engine.

Kolto Labs is a GitHub org, [github.com/kolto-labs](https://github.com/kolto-labs), for KotOR I and II tools. Two repos there are ready to use right now:

- **[kq](https://github.com/kolto-labs/kq)**, a command line for KotOR files. It reads an install in place and lets you query it like plain text: which copy of a resource the game loads, what's in it, where a string appears.
- **[kotor-formats](https://github.com/kolto-labs/kotor-formats)**, the format library kq uses. One copy of the byte layouts for KotOR I and II files, so the tools built on it cannot drift apart.

A third is early: **KPHarness**, a harness and TAS toolkit, KotOR I first and KotOR II planned. Its tools run on a stand-in game today. In the real game, exact replay (M1) has its first identical pair and is being re-verified.

Nothing else in the org is ready for use yet. If a repo is not named here, treat it as unfinished.

We don't ship game files. Every tool here expects you to bring your own copy.
